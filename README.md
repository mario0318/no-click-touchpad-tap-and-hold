# No-Click Touchpad: Tap & Hold

Windhawk mod that turns a tap in the corner of the touchpad into a right-click and a two-finger hold into a drag, for touchpads whose click no longer works.

Install it from [windhawk.net/mods/no-click-touchpad-tap-and-hold](https://windhawk.net/mods/no-click-touchpad-tap-and-hold). This copy tracks the one Windhawk installs.

Bugs and feature requests go in [issues](https://github.com/mario0318/no-click-touchpad-tap-and-hold/issues) here.
