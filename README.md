# No-Click Touchpad: Tap & Hold

Windhawk mod that turns a tap in the corner of the touchpad into a right-click and a two-finger hold into a drag, for touchpads whose click no longer works.

It's waiting for review in the Windhawk catalog ([ramensoftware/windhawk-mods#7443](https://github.com/ramensoftware/windhawk-mods/pull/7443)). Once it's merged you can install it from [windhawk.net/mods/no-click-touchpad-tap-and-hold](https://windhawk.net/mods/no-click-touchpad-tap-and-hold), and this copy tracks the one Windhawk installs.

Bugs and feature requests go in [issues](https://github.com/mario0318/no-click-touchpad-tap-and-hold/issues) here.
